arduino uno
1. Install arduino ide
   website: https://www.arduino.cc/en/software
2. upload fyp_arduino.ino to arduino from fyp_arduino

raspberry pi
1. Install Ubuntu 24.04.2 LTS in raspberry pi
   website: https://ubuntu.com/download/raspberry-pi
2. ip configuration
   website: https://www.freecodecamp.org/news/setting-a-static-ip-in-ubuntu-linux-ip-address-tutorial/
3. Install PyCharm Community Edition
   website: https://www.jetbrains.com/pycharm/download/?section=windows
